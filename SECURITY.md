# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.x | yes |

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's [security advisory form](https://github.com/Bokshorn-IT/filament-activity-timeline/security/advisories/new), or by email to mail@bokshorn.it.

Include the affected version, what an attacker can do with the issue, and steps to reproduce it if you have them.

You can expect a first reply within 7 days. If the report is confirmed, a fix is released as soon as it is ready and the advisory is published with credit to you unless you would rather stay anonymous.
